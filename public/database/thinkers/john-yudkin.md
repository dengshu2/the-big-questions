# 此人是谁

约翰·尤德金（John Yudkin，1910-1995），英国人，伦敦大学伊丽莎白女王学院营养学教授。他是最早系统性警告**糖的健康危害**的科学家。1972年他出版了《纯白，致命》一书，论证过量摄入糖（特别是蔗糖）是心脏病的主要风险因素——但他的观点被糖业资助的研究和支持"脂肪有害"理论的科学家联手压制了。他在学术界被边缘化直到去世。21世纪初，新的研究证实了他的很多论点。

# 核心贡献的来源

在1960-70年代，营养学界有一场关于"心脏病的饮食原因"的大辩论。安塞尔·基斯（Ancel Keys）主张**脂肪（特别是饱和脂肪）**是罪魁祸首。尤德金主张**糖**才是。基斯赢了这场政治和学术斗争——"低脂饮食"成为官方建议，食品工业用糖替代了脂肪来保持口感。几十年后，肥胖和糖尿病的流行证明了这个方向的严重错误。

# 必读著作

**《纯白，致命》（Pure, White and Deadly，1972/2012再版）**
先知式的著作。尤德金用当时有限的数据论证了过量摄糖与心脏病、肥胖和糖尿病的关联。这本书在2012年被再版，因为科学终于追上了他四十年前的预警。

# 现代人必须知道的3个核心概念

**一、糖是心脏病的独立风险因素**：不只是卡路里的问题——蔗糖和果糖的代谢方式（特别是对肝脏和胰岛素抵抗的影响）使它们在同等热量下比其他食物更有害。

**二、科学被产业利益扭曲**：糖业协会在1960年代秘密资助研究将心脏病的原因从糖转嫁到脂肪。这段历史是理解"利益冲突如何腐蚀科学"的经典案例。

**三、营养学的混乱根源**：营养学研究极难做（不能随机分配人吃几十年的不同饮食），导致它比其他科学领域更容易受到偏见、利益集团和媒体炒作的影响。

# 历史局限与反对者

**他的数据在当时确实不足以做出确定性的因果结论。** 现代研究在很大程度上支持了他关于糖的警告，但也表明营养与疾病的关系比"糖有害"更复杂——整体饮食模式、个体遗传差异和生活方式都很重要。

**反对者：安塞尔·基斯。** 基斯公开嘲讽尤德金的研究，并利用自己在学术界的影响力边缘化他。讽刺的是，基斯的"七国研究"后来被发现在数据选择上有严重问题——他挑选了支持自己假说的国家数据，忽略了不支持的。
