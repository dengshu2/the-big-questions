# 此人是谁

根里奇·阿奇舒勒（Genrich Altshuller，1926-1998），苏联人，发明家和发明方法论研究者，**TRIZ（发明问题解决理论）之父**。他15岁获得第一个发明专利，在苏联海军专利局工作时开始系统研究发明的规律。因给斯大林写信批评苏联的创新体制而被投入古拉格劳改营，在那里他继续发展TRIZ理论。1954年获释后，用余生将TRIZ发展为一套完整的创新方法论。

# 核心贡献的来源

阿奇舒勒的核心洞见是：**发明不是天才的灵感，而是有规律可循的**。他分析了超过400,000份苏联发明专利，发现绝大多数发明问题都可以归结为有限数量的"矛盾"类型，而解决这些矛盾的策略也是有限且可分类的——他总结出了40个发明原理。

# 必读著作

**《创新算法》（Алгоритм изобретения / Algorithm of Invention，1969/1973）**
TRIZ的核心著作。它将发明问题分为五个级别（从简单的参数优化到发现新的科学效应），并提供了系统性的解决工具——矛盾矩阵、物-场分析、技术系统进化规律等。

# 现代人必须知道的3个核心概念

**一、技术矛盾与40个发明原理**：当你试图改善系统的一个参数时，另一个参数恶化了——这是"技术矛盾"。阿奇舒勒发现大多数矛盾可以用40个通用原理来解决（如分割、合并、嵌套、反转、自服务等）。

**二、理想最终结果（Ideal Final Result, IFR）**：解决问题的方向应该朝着"理想最终结果"前进——系统自己执行所需功能，不增加成本和复杂性。这迫使发明者跳出当前方案的框架，想象"最好的可能结果"。

**三、技术系统进化规律**：技术系统不是随机发展的，而是沿着可预测的方向进化——从宏观到微观、从刚性到柔性、从低度到高度自动化。了解这些规律可以预测技术的发展方向。

# 历史局限与反对者

**TRIZ在工程领域外的适用性尚未充分验证。** TRIZ基于工程专利的分析，其核心概念（技术矛盾、物-场分析）对非技术问题的适用需要大量"翻译"工作。有些"管理TRIZ"的尝试显得牵强。

**反对者：创造力研究者。** 一些心理学家认为TRIZ过于机械化——真正的创新需要的是"打破框架"和"不可预测的联想"，而不是查矩阵表找对应原理。TRIZ可能更适合"改良"而非"颠覆"。
