# 此人是谁

艾萨克·牛顿（Isaac Newton，1643-1727），英国人，出生于林肯郡一个自耕农家庭，父亲在他出生前就去世了。他在剑桥三一学院求学时并不突出，但1665年伦敦大瘟疫迫使剑桥关闭，他回到乡下度过了传奇的"奇迹之年"——在不到两年里，他独自发展出微积分、万有引力理论和光学实验的基本框架。他性格孤僻、多疑、记仇，与莱布尼茨关于微积分发明权的争论持续了数十年。晚年他当了皇家铸币厂厂长，热衷于追捕伪币犯，也花了大量时间研究炼金术和解读《圣经》中的预言。

他活在科学革命的顶峰时刻。哥白尼、开普勒、伽利略已经分别在天文学和力学中取得了突破性成果，但这些成果是分散的——天上的运动和地上的运动似乎遵循不同的规律。牛顿做的事情是：用一套统一的数学语言把它们全部连接起来。

# 核心贡献的来源

牛顿最著名的贡献是**万有引力定律**和**经典力学三定律**。

逻辑链条如下：

开普勒发现行星沿椭圆轨道运行，伽利略发现地面上的物体遵循匀加速运动规律。但为什么行星走椭圆？为什么苹果往下掉？牛顿的核心洞见是：让苹果落地的力和让月亮绕地球转的力是**同一个力**——万有引力，它与质量成正比、与距离的平方成反比。

为了严格证明这一点，他需要一种新的数学工具来处理"瞬时变化率"——于是他发明了微积分（他称为"流数术"）。用微积分加上三条运动定律（惯性定律、F=ma、作用力与反作用力），他从万有引力出发推导出了开普勒的全部行星运动定律、潮汐现象、地球的扁球形状等等。

这个成就的震撼之处在于：整个宇宙——从水平的石子到旋转的星系——都遵循同一套简单的数学规律。

# 必读著作

**《自然哲学的数学原理》（Philosophiæ Naturalis Principia Mathematica，1687）**
现代科学史上最重要的单本著作，没有之一。它用几何证明的形式推导出了万有引力和经典力学的完整体系。原书极难读（牛顿故意写得难，"为了避免被数学程度不够的人纠缠"），但理解其结构就理解了"用数学描述自然"这一科学范式的原型。

**《光学》（Opticks，1704）**
比《原理》更易读，用实验而非数学证明的风格写成。牛顿用棱镜实验证明白光由各色光混合而成。书末附的"疑问"部分是牛顿罕见的思辨性写作，表达了他对物质本质的猜测，影响了后来整整一个世纪的物理学和化学。

# 现代人必须知道的3个核心概念

**一、万有引力（Universal Gravitation）**

原始含义：宇宙中任何两个有质量的物体之间都存在引力，引力大小与两者质量的乘积成正比、与距离平方成反比（F=Gm₁m₂/r²）。"万有"是关键词——同一个力既拉着苹果往下掉，也拉着月亮绕地球转。

它打开的未解问题：引力怎么做到"超距作用"？两个相隔亿万公里的星球怎么瞬间"感到"对方的存在？牛顿自己也承认无法解释引力传递的机制（"我不编造假说"）。这个问题直到爱因斯坦的广义相对论才有了回答：引力不是"力"，而是质量弯曲了时空。

现代发挥作用的领域：航天器轨道计算、GPS 卫星定位（需要考虑相对论修正）、天文学中暗物质的推断（星系旋转不符合牛顿引力预测，暗示有看不见的质量）。

**二、运动三定律（Three Laws of Motion）**

原始含义：第一定律（惯性）——物体保持静止或匀速直线运动，除非受到外力。第二定律——F=ma，力等于质量乘以加速度。第三定律——作用力与反作用力大小相等、方向相反。

它打开的未解问题：这些定律在日常尺度和速度下极其精确，但在接近光速或极小尺度下失效——前者需要相对论修正，后者需要量子力学。牛顿力学是"近似正确"的理论，这个事实引出了一个哲学问题：科学理论的"正确"意味着什么？是绝对真理还是"在特定范围内足够好的近似"？

现代发挥作用的领域：工程学的核心基础（建筑、桥梁、机械设计）、火箭推进原理（第三定律）、交通安全设计（惯性和F=ma）。

**三、微积分（Calculus / Fluxions）**

原始含义：处理"瞬时变化率"（微分）和"累积总量"（积分）的数学工具。牛顿（和莱布尼茨独立地）发明了它来解决运动和面积计算问题。速度是位置的微分，加速度是速度的微分——微积分让你能精确描述"连续变化"。

它打开的未解问题：牛顿时代的微积分在逻辑基础上有漏洞（"无穷小量"到底是零还是非零？），被贝克莱主教嘲笑为"已死之量的幽灵"。直到19世纪（柯西、魏尔斯特拉斯）才用极限理论严格化了微积分的基础。

现代发挥作用的领域：几乎所有定量科学和工程的数学基础、机器学习中的梯度下降（核心就是微分）、经济学中的边际分析、信号处理和图像识别。

# 历史局限与反对者

**他的绝对时空观被推翻了。** 牛顿认为存在"绝对空间"和"绝对时间"——它们是宇宙的不变背景，独立于任何物体和观察者。爱因斯坦在1905年证明这是错的：时间和空间是相对的，取决于观察者的运动状态。没有什么"宇宙通用的现在"。

**他的光粒子说曾经压制了正确的理论。** 牛顿主张光是粒子流，荷兰物理学家惠更斯主张光是波动。由于牛顿的巨大权威，粒子说在英国统治了一个世纪，阻碍了光学的发展。后来托马斯·杨和菲涅尔的实验确认了光的波动性。量子力学最终表明光既是粒子又是波，但牛顿时代的"粒子说"是基于错误的理由得出的。

**反对者一：莱布尼茨。** 莱布尼茨不仅在微积分发明权上与牛顿争斗，在哲学上也根本对立。莱布尼茨认为"超距作用"是荒谬的——宇宙中不存在没有中介的力。他批评牛顿的引力理论虽然数学上成功，但在物理解释上是"神秘的"。

**反对者二：恩斯特·马赫。** 马赫在19世纪末批判了牛顿的"绝对空间"概念——如果整个宇宙里只有一个物体，"它在旋转"这句话有意义吗？马赫认为没有，因为运动只有在相对于其他物体时才有意义。马赫的批判直接影响了爱因斯坦发展广义相对论。
