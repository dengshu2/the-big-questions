# 此人是谁

费尔南·布罗代尔（Fernand Braudel，1902-1985），法国人，20世纪最伟大的历史学家之一，法国年鉴学派的第二代领袖。他在阿尔及利亚和巴西教过书，二战期间被俘，在战俘营中凭记忆写出了他的巨著《地中海与菲利普二世时代的地中海世界》——没有任何参考资料。他后来主持法国高等研究实践学院和年鉴学派杂志，是法国学术界最有权力的人物之一。

他面对的核心问题是：历史只是由伟人、战争和政治事件构成的吗？他认为不是——在政治事件的"表面泡沫"之下，有更深层的力量在运作：地理环境、气候、人口变动、经济周期。这些"长时段"的结构变化才是真正塑造历史的力量。

# 核心贡献的来源

布罗代尔最著名的贡献是**三种历史时间**的概念：长时段（地理与结构，变化极其缓慢）、中时段（经济和社会周期，几十年到几百年）、短时段（政治事件，日常新闻式的叙述）。传统历史学只关注短时段（国王做了什么、战争怎么打的），布罗代尔认为真正重要的是那些几乎不被注意到的缓慢变化——地中海的洋流模式、山地经济的节奏、城市网络的演化。

# 必读著作

**《地中海与菲利普二世时代的地中海世界》（La Méditerranée，1949）**
历史学的"交响乐"。全书三部分对应三种时间尺度：第一部分写地中海的地理和环境（几乎不变的），第二部分写经济、社会和文化的缓慢变迁，第三部分才写菲利普二世的政治和军事。它示范了一种全新的历史写法——不是讲故事，而是揭示结构。

# 现代人必须知道的3个核心概念

**一、长时段（Longue Durée）**

原始含义：历史中那些变化极其缓慢、几乎被同时代人忽略的结构性力量——地理环境、气候模式、人口结构、技术基础。这些力量不是"事件"，而是事件发生的"舞台"。但舞台本身也在变——只是变化的速度慢到需要几个世纪才能察觉。

现代发挥作用的领域：气候变化史、环境史、世界体系理论、大历史（Big History）运动。

**二、物质文明（Civilisation Matérielle）**

原始含义：布罗代尔在《15至18世纪的物质文明、经济和资本主义》中提出的概念——在市场经济之下，还有一个更底层的日常生活世界：人们吃什么、穿什么、住什么样的房子、用什么工具。这个"物质文明"层面的变化比政治历史慢得多，但更深刻地决定了人类的生活方式。

现代发挥作用的领域：消费史、日常生活研究、物质文化研究、全球史中的物质交流。

**三、世界经济（Économie-Monde）**

原始含义：一个自给自足的经济空间，有自己的中心和边缘。威尼斯、阿姆斯特丹、伦敦先后担任过世界经济的中心城市。中心地区是资本主义和创新的核心，边缘地区提供原材料和廉价劳动力。

现代发挥作用的领域：沃勒斯坦的世界体系理论（直接继承）、全球化研究、国际发展不平等分析。

# 历史局限与反对者

**他几乎完全忽略了文化、思想和个人能动性。** 在布罗代尔的历史中，地理和经济是主角，人只是结构的被动产物。宗教、艺术、哲学几乎不起作用。他的历史学有时读起来像没有人的地理学。

**反对者一：微观史学（卡洛·金兹堡等）。** 微观史学家认为布罗代尔的宏大叙事牺牲了具体个人的生命经验。金兹堡的《奶酪与蛆虫》通过一个16世纪磨坊主的审判记录，展示了普通人的世界观——这恰恰是布罗代尔完全忽略的维度。

**反对者二：后殖民批评。** 布罗代尔的"世界经济"分析以欧洲为中心——中心总是在欧洲，非欧洲地区总是"边缘"。这忽略了亚洲（尤其是中国和印度）在15世纪前作为世界经济中心的漫长历史。
