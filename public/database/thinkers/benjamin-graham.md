# 此人是谁

本杰明·格雷厄姆（Benjamin Graham，1894-1976），英国出生、美国长大的投资者和学者，"价值投资之父"。他在哥伦比亚大学任教，最著名的学生是沃伦·巴菲特。他经历了1929年大崩盘的惨痛损失——正是这段经历促使他发展出一套基于理性分析而非市场情绪的投资方法论。

# 核心贡献的来源

格雷厄姆将股票投资从**投机**转变为一门有纪律的**分析学科**。核心洞见：股票不只是"涨跌的代码"，它代表一家真实企业的部分所有权。投资者的任务是计算企业的"内在价值"，然后在市场价格远低于内在价值时买入——这个差额就是"安全边际"。

# 必读著作

**《聪明的投资者》（The Intelligent Investor，1949）**
巴菲特称之为"有史以来最好的投资书"。它不教你选股技巧，而是教你正确的投资心态——将市场看成你的仆人而非你的主人（"市场先生"寓言），追求安全边际而非追逐涨跌。

# 现代人必须知道的3个核心概念

**一、安全边际（Margin of Safety）**

原始含义：只在市场价格显著低于你计算的内在价值时买入。这个"边际"是对你的分析可能有误的保护——即使你的估值算错了30%，只要你买入价足够低，你仍然有保障。

现代发挥作用的领域：价值投资实践、风险管理、工程设计中的安全系数思维、创业中的资源缓冲策略。

**二、市场先生（Mr. Market）**

原始含义：把市场想象成一个情绪不稳定的商业伙伴——他每天来敲你的门，出一个价格要买你的股份或卖给你他的股份。有时他乐观过头（出价太高），有时悲观过头（出价太低）。你可以利用他的情绪，但不应该被他的情绪感染。

现代发挥作用的领域：行为金融学、投资者心理学、对"市场有效性"假说的批评、个人理财中的情绪管理。

**三、内在价值（Intrinsic Value）**

原始含义：一家企业基于其资产、盈利能力和发展前景的"真实"价值。它与市场价格无关——市场价格反映的是情绪和预期，内在价值反映的是基本面。投资者的工作是估算内在价值，然后等待市场犯错。

现代发挥作用的领域：证券分析、企业估值方法论、并购定价、长期投资策略。

# 历史局限与反对者

**他的时代的信息环境与今天根本不同。** 格雷厄姆时代的投资者可以通过仔细阅读财务报告发现被市场忽视的"便宜货"。在今天，数以万计的分析师加上AI算法在毫秒级别分析每一条公开信息——低垂的果实已经很少了。

**反对者一：尤金·法马（有效市场假说）。** 法马认为市场已经反映了所有可获得的信息，长期跑赢市场是不可能的——格雷厄姆的"安全边际"在有效市场中不应该存在。对此格雷厄姆的回应是：市场大部分时候是有效的，但偶尔会犯巨大的错误，而这正是价值投资者的机会。

**反对者二：成长投资者（菲利普·费雪等）。** 费雪认为格雷厄姆的方法过于关注现有价值（用便宜的价格买平庸的企业），而忽视了成长的力量——用合理的价格买优秀的企业可能是更好的策略。巴菲特后来说自己是"85%格雷厄姆 + 15%费雪"。
