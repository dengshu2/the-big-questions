# 此人是谁

杰拉德·普林斯（Gerald Prince，1942-），美国人（法国出生），宾夕法尼亚大学法语和比较文学教授，**叙事学**领域的重要理论家。他是结构主义叙事学的代表人物之一，致力于建立分析叙事结构的形式化框架。

# 核心贡献的来源

普林斯的核心贡献是将叙事分析发展为一门有系统术语和分析工具的学科。他引入了"叙述接受者"（narratee）的概念——每个叙述不仅有"叙述者"（narrator），还有一个隐含的"被叙述的对象"。他还系统梳理了叙事学的基本概念并编纂了影响深远的叙事学词典。

# 必读著作

**《叙事学词典》（A Dictionary of Narratology，1987/2003）**
叙事学领域最有用的参考工具。它不是教科书而是词典——系统定义和解释了叙事分析的核心概念（聚焦、声音、时间、情节、叙述层次等）。适合任何需要精确谈论"故事如何运作"的人。

# 现代人必须知道的3个核心概念

**一、叙述接受者（Narratee）**：每个叙述都有一个隐含的听众——叙述者在"对谁说"影响了他怎么说。这不是真实的读者，而是文本内部构建的接收位置。

**二、叙事语法（Narrative Grammar）**：叙事像句子一样有结构规则。普林斯试图建立一种"叙事语法"来描述什么样的事件序列构成一个"故事"、什么不构成。

**三、可述性（Narratability / Tellability）**：什么使一个事件"值得讲"？普林斯探讨了叙事的"有趣性"条件——通常是偏离常规的事件、冲突和转折使一个事件序列变成"值得讲的故事"。

# 历史局限与反对者

**结构主义叙事学被批评为过于形式化。** 后结构主义和后殖民理论的批评者认为，把叙事简化为形式结构忽略了权力、身份和文化语境——谁在讲故事、为什么讲、对谁的利益服务，这些问题比"叙事结构"更重要。
