# 此人是谁

赫伯特·西蒙（Herbert A. Simon，1916-2001），美国人，20世纪最重要的社会科学家之一，也是少数真正的"文艺复兴人"——他在政治学、经济学、心理学、计算机科学和人工智能领域都做出了开创性贡献。1978年获诺贝尔经济学奖，1975年获图灵奖。他在卡内基梅隆大学任教近五十年，会说流利的中文（他的中文名字"司马贺"是他自己取的）。

他面对的核心问题是：经济学假设人是"完全理性"的——能搜集所有信息、评估所有选项、做出最优决策。但真实的人类显然不是这样。那人类到底是怎么做决策的？

# 核心贡献的来源

西蒙最著名的贡献是**有限理性（Bounded Rationality）**和**满足化（Satisficing）**。

核心洞见：人类的认知资源是有限的——我们的注意力、记忆、计算能力都有天花板。在一个信息过载、时间紧迫的世界里，追求"最优决策"不仅不可能，而且不合理（搜索"最优"本身的成本可能超过收益）。真实的人不是"最优化者"（optimizer），而是"满足化者"（satisficer）——他们搜索到一个"足够好"的选项就停下来了。

这个洞见从根本上挑战了经济学的理性人假设，并为行为经济学铺平了道路（卡尼曼明确将西蒙视为先驱）。

西蒙后来将注意力转向了人工智能——1956年他与纽厄尔一起创造了"逻辑理论家"程序，是最早的AI程序之一。他相信计算机可以模拟人类的思维过程——这个信念后来被称为"强AI假说"的一个版本。

# 必读著作

**《管理行为》（Administrative Behavior，1947/1997第四版）**
西蒙的博士论文改写的经典，为他赢得诺贝尔奖的核心著作。它分析了组织中的决策过程——人在组织环境中如何获取信息、评估选项、做出选择。核心论点：组织的功能是弥补个人理性的有限性——通过分工、层级、标准化程序和信息系统，组织使得个人有限的理性能够产生相对"理性"的集体决策。

**《人工科学》（The Sciences of the Artificial，1969/1996第三版）**
一本薄但深刻的书，讨论了"人造物"（产品、组织、计算机程序）的科学研究方法。核心概念是"设计科学"——与研究自然现象的科学不同，研究人造物的科学关注的是"事物应该怎样"而非"事物实际怎样"。

# 现代人必须知道的3个核心概念

**一、有限理性（Bounded Rationality）**

原始含义：人类的理性受到三重限制——获取信息的限制（你不可能知道一切）、认知加工的限制（你不可能评估所有选项）和时间的限制（你不能无限等待）。在这些约束下，人类使用简化的"启发式"（heuristics）来做决策，而不是经济学教科书中的"最优化计算"。

它打开的未解问题：有限理性到底是"足够好"（生态理性——启发式在真实环境中表现出色）还是"系统性有缺陷"（认知偏差——启发式导致可预测的错误）？吉仁泽站在前者一边，卡尼曼站在后者一边。这个辩论至今未决。

现代发挥作用的领域：行为经济学、组织决策理论、AI系统设计（让机器在有限资源下做"足够好"的决策）、公共政策设计（"助推"理论）。

**二、满足化（Satisficing）**

原始含义：西蒙造的词（satisfying + sufficing）。人在做决策时不是搜索所有选项找最好的，而是设定一个"接受门槛"，找到第一个达到门槛的选项就选它。买房子不是看完市面上所有房子选最好的——你看到一个"足够大、足够近、价格可接受"的就买了。

现代发挥作用的领域：消费者行为研究、算法设计（"足够好"的近似算法vs"最优"的精确算法）、职业选择咨询、时间管理策略。

**三、注意力经济（Attention as Scarce Resource）**

原始含义：西蒙在1971年就预言："在信息丰富的世界里，信息的丰富意味着其他东西的匮乏——被信息消费的东西的匮乏。信息消费的是接收者的注意力。因此，信息的丰富制造了注意力的匮乏。"

现代发挥作用的领域：注意力经济学、信息过载管理、社交媒体设计（争夺注意力）、"深度工作"方法论。

# 历史局限与反对者

**他对AI的乐观预测大多落空了。** 西蒙在1965年预言"二十年内机器将能做到人能做的任何工作"。这个预测在时间尺度上严重失误。他的"物理符号系统假说"（智能可以通过符号操作来实现）在联结主义和深度学习兴起后被认为过于狭隘——现代AI的成功更多依赖统计学习而非符号推理。

**反对者一：理性预期学派（卢卡斯等）。** 新古典经济学家认为西蒙低估了市场选择的力量——即使个人是"有限理性"的，市场竞争会淘汰那些做出系统性错误决策的人和企业，使得"好像理性"的结果出现。宏观层面的结果可以表现得好像参与者是完全理性的。

**反对者二：休伯特·德雷福斯。** 德雷福斯从海德格尔和梅洛-庞蒂的现象学出发批判了西蒙的AI研究——人类的智能不是"信息处理"和"符号操作"，而是基于身体经验的、情境化的"知道怎么做"（know-how）。机器不能真正"理解"，它们只是操作符号。
