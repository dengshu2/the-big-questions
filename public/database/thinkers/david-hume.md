# 此人是谁

大卫·休谟（David Hume，1711-1776），苏格兰人，爱丁堡大学出身，西方哲学史上最重要的经验主义者和怀疑论者之一。他年轻时写的《人性论》遭到冷遇（"从印刷机上一出生就死了"），但他毫不气馁，改写为更通俗的《人类理解研究》和《道德原理研究》后获得了巨大声望。他同时是一位杰出的历史学家——他写的《英格兰史》是 18 世纪最畅销的历史著作。晚年他是爱丁堡社交界的名人，性格温和幽默，被友人称为"好大卫"。

他活在苏格兰启蒙运动的黄金时代——爱丁堡和格拉斯哥汇聚了亚当·斯密、亚当·弗格森等一批天才。这个时代的核心问题是：理性到底能做什么？笛卡尔说理性能从"我思故我在"出发重建一切知识，莱布尼茨说理性能发现必然真理。休谟的回答是：你们都高估了理性的能力。

# 核心贡献的来源

休谟最著名的贡献是对**因果关系**的怀疑论分析和**经验主义认识论**。

逻辑链条如下：

你看到太阳每天升起，你说"太阳明天也会升起"。为什么？因为过去一直如此。但"过去一直如此"能证明"未来也会如此"吗？不能。过去重复一千次不等于第一千零一次一定会发生。这就是**归纳问题**——从有限的观察推断普遍规律，在逻辑上没有保证。

更根本地：你说"A 引起了 B"（比如"火引起了水沸腾"）。你真正看到了什么？你看到了 A 发生，然后 B 发生，而且这种先后关系反复出现。但你从未"看到"过"引起"本身。因果关系不是你在世界中观察到的东西，而是你的心灵基于习惯性联想投射到世界上的东西。

这个分析的破坏力是巨大的：它意味着科学的根基——因果推理和归纳法——在逻辑上是没有最终保证的。康德后来说，正是休谟"把他从独断论的迷梦中唤醒了"。

# 必读著作

**《人类理解研究》（An Enquiry Concerning Human Understanding，1748）**
休谟认识论的精华版。比早期的《人性论》更精炼、更清晰。核心章节是第四节（论因果推理）和第十节（论奇迹）。读它能理解为什么"科学地思考"和"逻辑上确定"是两回事——以及为什么这不是坏事。

**《道德原理研究》（An Enquiry Concerning the Principles of Morals，1751）**
休谟自认为是自己最好的作品。核心论点：道德判断不是理性推理的结果，而是情感反应。理性告诉你事实是什么，但"这件事好不好"是你的感受在说话。这个"情感主义"立场至今仍是伦理学的主要流派之一。

# 现代人必须知道的3个核心概念

**一、归纳问题（Problem of Induction）**

原始含义：从有限的过去经验推断未来或普遍规律，在逻辑上没有保证。太阳过去每天升起，不能逻辑地证明它明天也会升起。我们的归纳信念来自"习惯"和"心理期待"，而不是逻辑必然性。

它打开的未解问题：如果归纳法没有逻辑保证，科学知识的可靠性建立在什么基础上？波普尔试图用"证伪主义"绕过这个问题（科学不靠归纳，靠"尝试推翻假说"），但很多哲学家认为他没有真正解决它。贝叶斯学派试图用概率论框架重新定义"合理信念"的标准。这个问题至今没有共识。

现代发挥作用的领域：机器学习的理论基础（用过去的数据预测未来本质上就是归纳）、统计推断的哲学基础、贝叶斯推理框架、大数据时代"相关性≠因果性"的方法论警示。

**二、是/应该问题（Is-Ought Problem / Hume's Guillotine）**

原始含义：你不能从"是什么"的事实判断直接推导出"应该怎样"的价值判断。"人天生自私"（如果这是事实）不能推出"人应该自私"。事实和价值之间有一条逻辑鸿沟。被称为"休谟铡刀"。

它打开的未解问题：如果事实不能决定价值，道德判断的根据是什么？这直接催生了元伦理学——专门研究"道德判断的性质"的哲学分支。自然主义者试图用进化心理学等方式重新连接事实和价值，但休谟铡刀至今仍是伦理学辩论的基本工具。

现代发挥作用的领域：AI 伦理（算法能做的不等于算法应该做的）、政策制定中"科学建议"与"价值选择"的区分、生物伦理学、环境伦理。

**三、因果怀疑论（Causal Skepticism）**

原始含义：我们从未直接观察到"因果力"本身。我们看到的只是恒常连结（constant conjunction）——A 发生后 B 总是跟着发生。"A 引起 B"这个判断是我们的心灵基于反复经验形成的习惯性联想，不是对世界结构的直接洞察。

它打开的未解问题：因果关系到底是客观存在于世界中的，还是人类认知的投射？现代物理学（量子力学）中的因果概念已经远远超出了休谟时代的日常经验——"观测行为影响被观测对象"这种说法，休谟的框架能处理吗？

现代发挥作用的领域：实验科学中的因果推断方法论（随机对照实验、朱迪亚·珀尔的因果推断框架）、流行病学中的"相关不等于因果"原则、AI 中因果推理与相关性学习的区分。

# 历史局限与反对者

**他的怀疑论可能"太成功了"。** 如果连因果关系和归纳法都没有逻辑保证，那我们似乎不能合理地相信任何关于世界的一般性知识。休谟自己的解决方案是"自然信念"——我们天生就会相信因果关系，不需要逻辑保证。但这个回答让很多人不满意：它等于说"我们相信因为我们忍不住要相信"，这还算哲学论证吗？

**反对者一：伊曼努尔·康德。** 康德说休谟是对的——因果关系不来自经验。但康德的结论是：因果关系是人类认知的先天结构，是我们理解任何经验之前就必须具备的"范畴"。不是世界告诉我们有因果关系，而是我们的心灵把因果结构强加给了经验。休谟说因果是"习惯"，康德说因果是"先天必然"。

**反对者二：卡尔·波普尔。** 波普尔接受了休谟对归纳法的批判，但拒绝了他的"习惯心理学"解释。波普尔说科学根本不靠归纳——科学家不是从观察总结规律，而是大胆猜测然后严格试图推翻。一个理论只要还没被推翻，就暂时值得接受。波普尔把休谟的破坏性怀疑转化为建设性的科学方法论。

**他对非欧洲世界基本无知。** 休谟的哲学和历史著作几乎完全局限于欧洲经验。他在种族问题上有公开的偏见言论，2020 年爱丁堡大学将以他命名的大楼改名。这提醒我们，启蒙运动的"普遍理性"往往有一个隐含的限定条件。
