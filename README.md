# 大问题 · The Big Questions

人类文明经典元典导览 — 从十一个大问题出发，探索 300+ 位思想家与 900+ 部经典著作的智慧图谱。

## 数据来源

`public/database/canon.csv` — 920 条经典著作记录，涵盖：

| 维度 | 数量 |
|------|------|
| 大问题 | 11 |
| 章节 | ~50 |
| 学科/领域 | ~100 |
| 思想家 | 300+ |
| 经典著作 | 920 |
| 时间跨度 | ~2500 年 |

## 技术栈

- **Vite** + **React** + **TypeScript**
- **Vanilla CSS** 设计系统

## 开发

```bash
npm install
npm run dev
```
