# 此人是谁

菲利普·科特勒（Philip Kotler，1931-），美国人，西北大学凯洛格管理学院教授，**现代营销学之父**。他不是营销学的发明者，但他是系统化和学科化的人——他的教科书《市场营销管理》自1967年首版以来再版十余次，是全球商学院最广泛使用的营销教材。

# 核心贡献的来源

科特勒将营销从"推销和广告"提升为一门以**消费者需求为中心**的管理科学。他的核心洞见是：营销不始于产品，始于消费者的需要和欲望。企业的任务不是"卖出去已经做好的东西"，而是"发现人们需要什么然后创造它"。

# 必读著作

**《营销管理》（Marketing Management，1967-至今）**
营销学的"圣经"。它构建了营销的系统性框架——STP（市场细分、目标市场选择、定位）和4P（产品、价格、渠道、促销），并持续更新以纳入数字化、社交媒体和全球化的新现实。

# 现代人必须知道的3个核心概念

**一、STP策略**：市场细分（Segmentation）→ 目标市场（Targeting）→ 定位（Positioning）。不是"卖给所有人"，而是"选择你能最好服务的人群，然后在他们心中建立独特的位置"。

**二、4P框架**：Product（产品）、Price（价格）、Place（渠道）、Promotion（促销）。这四个维度共同构成了营销决策的基本空间。后来被扩展为7P、4C等变体，但基本框架至今有效。

**三、社会营销（Social Marketing）**：科特勒将营销的思路应用到非商业领域——公共健康、环保、社会变革。"卖"一个健康的生活方式和"卖"一瓶可乐在方法论上是相似的。

# 历史局限与反对者

**营销学的"操纵"嫌疑。** 批评者认为科特勒体系化的营销方法本质上是系统性地操纵消费者决策——利用心理弱点来刺激不必要的消费。科特勒本人强调"好的营销是创造真实价值"，但实践中两者的界限往往模糊。

**反对者：去增长运动和消费批判理论。** 从波德里亚的消费社会批判到当代的去增长运动，营销被视为消费主义的核心驱动力——系统性地制造"需求"（而非满足需求），推动了不可持续的经济增长模式。
