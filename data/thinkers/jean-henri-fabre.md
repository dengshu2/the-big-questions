# 此人是谁

让-亨利·法布尔（Jean-Henri Casimir Fabre，1823-1915），法国人，昆虫学家和博物学家，被称为"昆虫界的荷马"。他出身贫寒，完全靠自学成为学者。他在法国南部普罗旺斯用近四十年时间观察昆虫行为，写出了十卷本的《昆虫记》。他的研究方法是直接在自然环境中长时间观察活的昆虫，而不是在实验室里解剖死的标本——这在当时是革命性的。

# 核心贡献的来源

法布尔的核心贡献是**将严谨的科学观察与优美的文学叙述结合**，创造了一种全新的博物学写作风格。他描述的蜘蛛织网、蝎子求偶、粪金龟推粪球不是干巴巴的数据报告，而是充满戏剧性的生命故事。他证明了昆虫行为的惊人复杂性——泥蜂精确地麻痹猎物而不杀死它，以保持食物的新鲜。

# 必读著作

**《昆虫记》（Souvenirs entomologiques，1879-1907）**
十卷本的昆虫行为观察巨著。每一章以某种昆虫为主角，用第一手观察数据和生动的叙述揭示昆虫世界的奇观。达尔文称法布尔为"无与伦比的观察者"。读它能获得一种对自然界"慢下来、仔细看"的能力和对生命多样性的惊叹。

# 现代人必须知道的3个核心概念

**一、田野观察法**：法布尔坚持在自然条件下观察昆虫，反对仅靠解剖和分类来理解生命。这种方法后来发展为现代动物行为学（ethology）的基础。

**二、本能行为的精密性与局限性**：法布尔发现昆虫的本能行为极其精密但也极其刻板——如果实验者干扰了行为链条的某个环节，昆虫不会"调整策略"而是重复或停滞。这揭示了本能与智能的根本区别。

**三、"科学叙事"的力量**：法布尔证明了科学不必是枯燥的——精确的观察完全可以用引人入胜的方式呈现。他影响了后来所有优秀的科普写作。

# 历史局限与反对者

**他拒绝接受达尔文的自然选择理论。** 法布尔认为昆虫本能的精密性不能用逐步的自然选择来解释——这些行为太复杂了，必须是"一步到位"的。现代演化生物学证明他在这一点上是错的，本能行为确实可以通过逐步的选择过程演化。

**反对者：实验室生物学家。** 一些同代生物学家批评法布尔的方法不够"科学"——他缺乏对照实验，有时将人类情感投射到昆虫行为上（拟人化），而且他的观察难以被精确重复。
