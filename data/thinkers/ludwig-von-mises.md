# 此人是谁

路德维希·冯·米塞斯（Ludwig von Mises，1881-1973），奥地利裔美国人，奥地利经济学派的核心人物。出生于奥匈帝国的伦贝格（今乌克兰利沃夫）的一个犹太家庭。1940年逃离纳粹欧洲到美国，在纽约大学以"访问教授"身份任教到87岁——他的工资不是大学付的，而是私人基金会赞助的，因为他的极端自由市场立场让主流经济学界对他敬而远之。

他活在两次世界大战之间中央计划经济兴起的年代。苏联的五年计划似乎证明了社会主义可以"科学地"管理整个经济。米塞斯在1920年就提出了一个根本性的挑战：没有市场价格，社会主义经济不可能进行合理的资源配置——这就是著名的**经济计算问题**。

# 核心贡献的来源

米塞斯最著名的贡献是对**社会主义经济计算不可能性**的论证和**人类行动学**。他的核心论证是：在没有私有产权和自由市场的情况下，生产资料没有市场价格，而没有价格就无法比较不同生产方式的成本和效率。中央计划者即使有最好的意图和最强大的计算机，也无法替代市场的价格信号机制。

# 必读著作

**《人类行动》（Human Action，1949）**
米塞斯的巨著，奥地利学派经济学的系统性总结。从"人类行动"的基本公理出发，用纯逻辑推理（而非统计数据）构建了整个经济学理论。极其厚重但逻辑严密。读它能理解一种完全不同于主流经济学的方法论——经济学不是自然科学，不能做实验，必须从"人有目的地行动"这一先验事实出发。

# 现代人必须知道的3个核心概念

**一、经济计算问题（Economic Calculation Problem）**

原始含义：社会主义中央计划经济因缺乏市场价格信号而无法合理配置资源。价格不只是"标签"——它凝缩了无数分散的供需信息。取消市场就是取消这个信息系统，计划者将在黑暗中决策。

现代发挥作用的领域：转型经济学（苏联解体后的市场化改革验证了米塞斯的预言）、平台经济中的定价算法、区块链经济的去中心化激励设计。

**二、人类行动学（Praxeology）**

原始含义：一种从"人有目的地行动"这一不可否认的公理出发，通过纯逻辑推理得出经济学定理的方法。米塞斯认为经济学不需要也不能依赖经验数据的统计验证——经济规律是先验为真的。

现代发挥作用的领域：方法论辩论（经济学是像数学一样的演绎科学还是像物理学一样的经验科学）、奥地利学派的学术传统。

**三、企业家精神（Entrepreneurship）**

原始含义：企业家不只是管理者——他是在不确定性中做决策的人，他发现价格信号中的不协调（利润机会），通过行动消除这种不协调。经济发展的动力不是机械的"均衡"，而是企业家对利润机会的警觉和冒险。

现代发挥作用的领域：创业理论（柯兹纳发展的"企业家警觉"概念）、创新经济学、风险投资的哲学基础。

# 历史局限与反对者

**他的方法论被主流经济学视为不科学。** 拒绝统计验证、只用纯逻辑推理的方法论使米塞斯的经济学无法产生可检验的预测——在实证主义主导的现代经济学界，这意味着被边缘化。

**反对者一：奥斯卡·兰格。** 兰格在"社会主义计算辩论"中提出了一个理论上的解决方案：社会主义计划者可以通过"试错法"模拟市场价格。米塞斯和哈耶克认为这在实践中不可行，苏联经济的最终崩溃在很大程度上证明了他们是对的。

**反对者二：凯恩斯主义传统。** 凯恩斯主义者认为米塞斯对政府干预的全面反对过于极端——市场有系统性失灵的时候（大萧条、金融危机），政府干预不是对自由的侵犯而是对秩序的恢复。
